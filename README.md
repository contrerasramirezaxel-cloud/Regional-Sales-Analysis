# [Project Name: Regional Sales Analysis & Automation]

*(All resources, documents, and files are included directly in this repository folder)*

## 📝 Project Description
This project focuses on conducting a detailed sales analysis for **three specific countries**, evaluating commercial behavior, product performance, customer demand, and transaction trends in these defined markets. It solves the challenge of consolidating information from different territories to understand exactly how sales behave in each location, identifying the most demanded products, seasonal variations, and opportunities by country. The value it provides is a clear, segmented view that allows adapting commercial strategies specifically for these markets, optimizing inventory and marketing actions based on real data from these regions.

## ✨ Key Features / Main Results
*   **[Feature 1]:** Advanced data extraction using **SQL**, including complex queries, `JOINS` to combine sales records, product catalogs, customer information, and geographic data. I applied specific filters for the **three target countries**, grouping functions, and custom calculations to obtain exact results for each location, comparing results between them and generating consolidated reports. *(SQL scripts available inside the repository)*
*   **[Feature 2]:** Massive processing and automation with **Python**, used to clean, standardize, and organize large volumes of transactional data, eliminating duplicates, correcting formats, and automating the segmentation process by country to ensure data consistency and speed in updates. *(Python code available inside the repository)*
*   **[Feature 3]:** **Manual Structuring & Quality Validation:** After automatic processing, I performed detailed **manual organization, structuring, and validation in Excel**, applying commercial rules and specific criteria for each country to verify that every record, amount, and classification is correct, logical, and adjusted to the reality of each market. **This is my main strength: I do not rely only on automation; I personally review every detail to ensure the data is 100% reliable and accurate.** *(Final structured dataset available inside the repository)*
*   **[Result/Value Added]:** Design and development of an interactive dashboard in Power BI to visualize key indicators such as total sales by country, best-selling products, comparison between markets, customer segmentation, and demand trends. This allows understanding exactly what happens in each territory, making decisions focused on increasing sales and improving results in these three specific countries. *(Power BI file available inside the repository)*
