## 📝 Project Description
This project consists of evaluating the operational and commercial performance of different regions to define strategic actions, optimize resources, and achieve business objectives. It addresses the challenge of interpreting complex data to transform it into useful information for decision-making, combining technical data processing with a deep understanding of business goals. The value it delivers is providing a clear view of how each area is performing, identifying strengths and opportunities, and creating strategies that help companies grow, reduce costs, and maximize results in each market.

## ✨ Key Features / Main Results
*   **[Feature 1]:** Advanced data extraction using **SQL**, including complex queries, `JOINS` to integrate performance indicators, operational metrics, financial data, and regional characteristics from multiple databases. I also developed calculations, comparisons, and time series analysis to understand how each region evolves and performs relative to others. *(SQL scripts available inside the repository)*
*   **[Feature 2]:** Massive processing and automation with **Python**, used to process large datasets, standardize information, detect anomalies, and automate data preparation tasks, allowing faster and more efficient analysis of large volumes of information. *(Python code available inside the repository)*
*   **[Feature 3]:** **Manual Structuring & Quality Validation:** After automatic processing, I performed detailed **manual organization, structuring, and validation in Excel**, applying strategic business rules and logical criteria to ensure every single data point is correct, relevant, and perfectly adapted to the needs of the company. **This is my main strength: I combine the efficiency of automation with the precision of human review to ensure the information is not only accurate but also meaningful for the business.** *(Final structured dataset available inside the repository)*
*   **[Result/Value Added]:** Design and development of an interactive dashboard in Power BI to visualize key strategic indicators, performance comparisons, growth opportunities, and action plan tracking. This allows managers to monitor results, make informed decisions, and implement strategies that generate tangible improvements in business performance. *(Power BI file available inside the repository)*
